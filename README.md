# 心格 MindGrid · 个人构念探索

帮助个人与咨询师用自己的语言提取构念、记录评分、核对探索线索，并选择后续行动。

## 打开使用

本机可双击 **启动心格.command**，然后打开终端显示的本地地址。此启动器直接使用已构建的 dist，运行时不需要安装依赖。

开发环境：Node.js 20.19+ / 22.12+，执行：

```bash
npm ci
npm run dev
```

打开 http://127.0.0.1:3000 。请通过本地服务运行，直接双击 dist/index.html 可能因浏览器模块策略无法加载。

## 第一版功能

- 个人探索 / 咨询协作入口，共用五步流程。
- 暖纸、陶土与鼠尾草配色；手机按单组构念评分，平板与电脑支持更宽布局。
- 随机三元比较减少重复；咨询师手动选择人物。
- 构念例子、编辑、移除与最近一次移除撤销；构念含义改变时清除该构念评分。
- 1–7 分、不了解、暂不评分分别记录；定位未评分项。
- 描述性指标、明确的有效数据量、可调整的分析参数；用户可反馈是否认同线索。
- 自我反思与可选 CBT 情境、预测、情绪、价值、行动和复盘记录。
- 可选浏览器本地保存、刷新恢复、JSON 会话导入导出。
- 私人笔记默认收起，PDF 默认排除；AI 材料始终排除私人笔记。
- 分页 PDF 与可预览、可代号替换的 AI 讨论材料；不会自动发送给外部 AI。

## 保存与边界

默认只在当前页面保留会话。开启本地保存后，内容存入当前浏览器的 localStorage，未加密。关闭保存会删除这个浏览器中的副本，不会自动删除下载的文件。

每个浏览器只维护一个当前会话；开始新会话或导入会替换它。请通过 JSON 备份分别保存不同来访者或不同时间的记录。导入仅接受此版本的会话文件。多人同时使用、多标签页并行编辑和云端同步不属于这一版本。

开启保存后，已记录数据和构念输入草稿均可恢复；“添加人物”框中尚未点击添加的文字不算已录入人物。关闭私人笔记只隐藏界面，不是密码保护。报告下载后的文件需自行妥善保管。

PDF 为分页图像报告，用于阅读和打印，文字不可直接选取；完整可编辑数据保留在 JSON 备份中。人物代号替换不能保证自由文本完全匿名，复制材料前请预览检查。

本工具不提供诊断，不将相关当作因果，不把缺失当中点，也不把未检出线索解释为没有心理冲突。完整规则见 [METHODS.md](METHODS.md)。

## 验证与构建

```bash
npm test
npm run lint
npm run build
```

产物在 dist，可用于本地启动器与 GitHub Pages 静态托管。推送到 main 后，GitHub Actions 会重新构建并部署。

技术栈：React 19、TypeScript、Vite、Tailwind CSS、Lucide、html2canvas、jsPDF。保留原有依赖体系，按兼容版本更新锁文件。测试覆盖相关系数边界、两极反转、缺失评分、导入验证与笔记导出边界。

## 使用前建议

先用虚构案例熟悉五步流程与保存方式，再用于实际探索。软件测试与方法文档不等于临床有效性验证。
